# Low vision, keyboard first

- **Who:** an adult who plays with the browser or system zoom turned up and prefers the keyboard.
  Has trouble telling red from green.
- **Why they're here:** to play like anyone else, without squinting or hunting for the mouse.
- **Manual:** reads the controls section, then plays.
- **Plays like:** zooms the page up (or plays at the largest window), uses the keyboard wherever
  the game allows, reads labels rather than colors.
- **Notices:** text too small to read, controls the keyboard can't reach, focus that disappears,
  information carried only by color.
- **Quits when:** something they need can only be read by color or only reached by mouse.
- **Budget:** one session.

Specialize: the game's keyboard controls and any color-coded meters or teams. Report only what's
seen; this card doesn't stand in for an accessibility audit.
